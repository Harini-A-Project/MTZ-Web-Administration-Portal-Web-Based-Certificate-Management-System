# 🌐 MTZ Web Administration Portal

### 📜 Web-Based Certificate Management System

---

## 📌 About the Project

The **MTZ Web Administration Portal** is a web-based administration and certificate management system developed during my internship at **Meridian Tech Zone, Karaikudi**.

The project was designed to reduce manual work and improve the management of student certificate information through a centralized web application. It includes certificate data processing, feedback management, database operations, authentication, and a user-friendly interface.

---

## 🎯 Project Objective

The main objective of this project was to develop a web-based system that can:

- 📋 Manage student certificate information
- 💾 Store and retrieve data efficiently
- 🔄 Perform CRUD operations
- 📝 Manage feedback and queries
- 🔐 Provide basic authentication and access control
- ⚡ Reduce manual data handling
- 📊 Improve the efficiency of administrative activities

## ✨ Key Features

### 📜 Certificate Management
- Add and manage student certificate details
- Store certificate number, course, duration, and grades
- Update existing certificate records
- Process certificate information through the web interface

### 📝 Feedback Management
- Collect feedback and queries from users
- Store feedback details in the database
- Retrieve and display submitted feedback

### 🔐 Authentication
- Basic admin login functionality
- Authentication for accessing administrative operations
- Input validation for data handling

### 🗄️ Database Management
- MySQL-based relational database
- CRUD operations for certificate and feedback records
- Structured storage of student and certificate information

---

## 📂 Project Modules

### 1️⃣ Certificate Module
The certificate module manages student certificate information such as:

- Student Reference ID
- Student Name
- Certificate Number
- Certificate Date
- Course
- Course Duration
- Overall Grade
- Theory Grade
- Practical Grade

### 2️⃣ Feedback Module
The feedback module handles:

- Name
- Email
- Contact Number
- State
- Feedback / Query

### 3️⃣ Admin Module
The administration module provides basic login functionality and access to administrative operations.
